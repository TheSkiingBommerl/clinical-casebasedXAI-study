# ECG-FM

## Set-up
To use the ecg-fm model you have to clone following repository: https://github.com/bowang-lab/ECG-FM/ [[1]](#1). Then, follow the provided instructions in that repository to download the model weights.

## Experiment 1
In Experiment 1, we used the model to generate embeddings of the data (see file: [create_embeddings](create_embeddings.py)).
