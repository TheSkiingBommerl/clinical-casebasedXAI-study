# Automatic ECG Diagnosis

## Set-up
To use the automatic-ecg-diagnosis model you have to clone following repository: https://github.com/antonior92/automatic-ecg-diagnosis [[1]](#1). Then, follow the provided instructions in that repository to download the model weights.

## Experiment 1
In Experiment 1, we used the model to generate embeddings of the data (see file: [create_embeddings](create_embeddings.py)).

## Experiment 2
In Experiment 2, we used the models predictions and their associated certainty scores.
